# AWS Amplify Notes App

A fullstack cloud-connected Notes application built with React and AWS Amplify. Features user authentication, a real-time GraphQL API, and persistent data storage — all provisioned and managed through the Amplify CLI.

---

## Features

- **Authentication** — Email-based sign up, sign in, and sign out via AWS Cognito, wrapped with the `withAuthenticator` HOC (full login wall out of the box)
- **Create notes** — Submit a name and description via a form; writes to DynamoDB through AppSync
- **List notes** — Fetches all notes on load via GraphQL query
- **Delete notes** — Removes a note from the UI optimistically and deletes from the database
- **Amplify UI** — Built entirely with `@aws-amplify/ui-react` components

## AWS Infrastructure

| Service | Configuration |
|---|---|
| **Cognito User Pool** | Email as required attribute, email verification, 8-char minimum password, MFA off |
| **Cognito Identity Pool** | Unauthenticated access disabled |
| **AppSync GraphQL API** | `Note` model with `id`, `name`, `description` fields; public auth rule |
| **DynamoDB** | Auto-provisioned by Amplify's `@model` directive |

---

## GraphQL Schema

```graphql
type Note @model @auth(rules: [{ allow: public }]) {
  id: ID!
  name: String!
  description: String
}
```

Amplify auto-generates full CRUD operations from this schema:
- `listNotes` — query
- `createNote`, `updateNote`, `deleteNote` — mutations
- `onCreateNote`, `onUpdateNote`, `onDeleteNote` — subscriptions (generated, available for extension)

## Getting Started

### Prerequisites

- Node.js 16+
- AWS account
- Amplify CLI (`npm install -g @aws-amplify/cli`)

### Install dependencies

```bash
npm install
```

### Initialize Amplify backend

```bash
amplify init
amplify push
```

### Run locally

```bash
npm start
```

## Key Implementation Details

- **`generateClient()`** — uses Amplify v6's `generateClient` pattern from `aws-amplify/api` for all GraphQL calls, migrated from the deprecated `API` class to stay current with breaking changes across Amplify versions
- **`withAuthenticator` HOC** — wraps the entire app, providing a complete sign-up/sign-in/sign-out flow with zero custom auth UI code; injects a `signOut` prop passed directly to the Sign Out button
- **Optimistic delete** — filters the note out of local state immediately on delete, then fires the GraphQL mutation asynchronously for a snappy UI
- **FormData API** — uses the native browser `FormData` to read form field values on submit rather than controlled inputs, keeping the component stateless for the form itself
